# Gerador de Códigos de Ativação - UnitvFree 5.2

Sistema evoluído para gerar códigos de ativação no formato exato utilizado pelo **Ativador UnitvFree 5.2**.

## Arquivos Criados

| Arquivo | Descrição |
|---|---|
| `gerador_unitvfree_gui.py` | Interface gráfica principal (recomendada) |
| `gerador_unitvfree_real.py` | Módulo de geração (console/teste) |
| `Gerador UnitvFree 5.2 TRONIX.bat` | Atalho na Área de Trabalho e pasta |

## Atalho Rápido

**Na Área de Trabalho:** `Gerador UnitvFree 5.2 TRONIX.bat` → Abre o gerador

## Como Usar

1. Clique em `Gerador UnitvFree 5.2 TRONIX.bat` (Área de Trabalho)
2. Defina a quantidade de códigos (1 - 500)
3. Clique em `GERAR CÓDIGOS DE ATIVAÇÃO`
4. Use os botões para:
   - **COPIAR SELECIONADO** - Copia um código específico
   - **COPIAR TODOS** - Copia todos os códigos gerados
   - **SALVAR .TXT** - Exporta em arquivo de texto
   - **VALIDAR SELECIONADO** - Verifica se o checksum está correto
   - **LIMPAR** - Limpa a lista

## Características

- **Formato:** Exatamente 11 dígitos numéricos
- **Checksum:** Algoritmo de validação mod10 alternado (peso 1,2 da direita p/esquerda)
- **Geração única:** Alta entropia com random + time
- **Lotes grandes:** Suporta até 500 códigos por geração
- **Validação interna:** Botão para validar qualquer código gerado
- **Pronto para uso:** Coloque direto no Ativador UnitvFree 5.2

## Exemplo de Códigos Gerados

```
41032603318
35811763713
30221617314
50379428147
34334624358
```

Todos com checksum válido (passam na validação).

## Recomendação

Use o arquivo `Gerador UnitvFree 5.2 TRONIX.bat` que está na **Área de Trabalho**. É o mais prático para uso diário.
