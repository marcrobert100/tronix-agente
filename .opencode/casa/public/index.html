📖 Como conectar

  1. Aguarde o QR Code aparecer (pode demorar ~1 min na primeira vez)
  2. Abra o WhatsApp no celular
  3. Vá em Aparelhos conectados → Conectar aparelho
  4. Aponte a câmera para o QR Code
  5. Quando aparecer "WhatsApp conectado!", está pronto!
⚠️ Se não conectar: Clique em "Limpar sessão" e escaneie o novo QR Code gerado.
