🚀 COMO USAR O ZIP EM OUTRA MÁQUINA:

OPÇÃO 1 - Instalação Completa (RECOMENDADA):
   1. Copie o arquivo delivery_bot.zip para a nova máquina
   2. Extraia o ZIP em qualquer pasta
   3. Execute o arquivo instalar_bot.bat
   4. Aguarde a instalação automática
   5. Clique no atalho criado no desktop

OPÇÃO 2 - Instalação Manual:
   1. Extraia o ZIP
   2. Copie a pasta "bot" para o desktop
   3. Abra CMD na pasta bot\Scripts
   4. Execute: call INICIAR.bat
   5. Acesse: http://localhost:3000

🔄 ATUALIZAÇÃO DO BOT:

Para atualizar o bot em qualquer máquina:
1. Pare o bot (feche a janela do CMD)
2. Copie os novos arquivos para a pasta do bot
3. Abra CMD na pasta do bot
4. Execute: npm install
5. Inicie novamente com INICIAR.bat

🆘 SOLUÇÃO DE PROBLEMAS:

- Se Node.js não estiver instalado: https://nodejs.org/

- Se o WhatsApp não conectar: limpe a sessão no painel
