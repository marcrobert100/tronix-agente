🚀 COMO USAR:

OPÇÃO 1 - Instalação Completa (se tiver os arquivos originais):
   1. Clique duas vezes em "instalar_bot.bat"
   2. Aguarde a instalação
   3. Clique no atalho "Iniciar Bot" no desktop

OPÇÃO 2 - Instalação Simples (para computadores novos):
   1. Clique duas vezes em "instalar_bot_simples.bat"
   2. Aguarde a instalação
   3. Execute o arquivo "INICIAR.bat" na pasta bot

🔄 ATUALIZAÇÃO:

Para atualizar o bot:
1. Pare o bot (feche a janela do CMD)
2. Copie os novos arquivos para a pasta "bot"
3. Abra CMD na pasta "bot" e execute: npm install
4. Inicie novamente com INICIAR.bat
