# Design Visual - Carrossel IA para Empresas

## Designer Visual | 05/05/2026

### Especificações Gerais
- **Formato:** Carrossel Instagram
- **Quantidade de slides:** 7
- **Dimensões:** 1080x1080px
- **Estilo:** Moderno e limpo

### Design por Slide

#### Slide 1 - Capa
```
Fundo: Gradiente azul (#0066FF → #8B5CF6)
Ícone: 🤖 grande centralizado
Título: "5 Ferramentas de IA" (branco, 48px, Bold)
Subtítulo: "que Aumentam sua Produtividade em 50%" (branco, 24px)
Elemento: Linha decorativa branca
Logo: Tech Solutions canto inferior direito
```

#### Slides 2-6 - Conteúdo
```
Fundo: Branco (#FFFFFF)
Cabeçalho: Faixa azul (#0066FF) com número e título
Ícone: Grande, centralizado, cor tema do slide
Conteúdo: 2-3 bullets com ícones ✓
Dica: Box cinza claro (#F1F5F9) na parte inferior
Logo: Canto inferior direito (pequeno)
```

#### Slide 7 - CTA
```
Fundo: Roxo (#8B5CF6)
Ícone: 💡 grande
Título: "Implemente essas ferramentas hoje!" (branco, 36px)
CTA: "Qual você já usa? Comente 👇" (branco, 24px)
Elementos: Ícones de comentário e salvamento
Logo: Tech Solutions (branco)
```

### Instruções para Criação
1. Manter consistência visual em todos os slides
2. Usar cores da paleta sem misturar
3. Garantir contraste suficiente para legibilidade
4. Centralizar elementos principais
5. Deixar espaçamento adequado nas bordas
