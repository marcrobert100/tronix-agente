# Criador de Conteúdo Educacional

## Menu de Opções
1. **Post único** - Criar um post educativo
2. **Carrossel** - Criar conteúdo em formato carrossel
3. **Script de Reels** - Criar roteiro para vídeo curto
4. **Legenda otimizada** - Otimizar legenda existente

## Instruções
- Mantenha o tom profissional da marca Tech Solutions
- Use formatação clara com emojis moderados
- Inclua sempre um CTA no final
- Limite de 2.200 caracteres para legendas
