📈 Opções de Trading

Call Option (Opção de Compra)

Direito de comprar uma ação a um preço fixo (strike) até uma data específica.

Exemplo:
AAPL a $150 → Call $155
Se AAPL > $155: Lucro = (Preço - $155) - Premium
Se AAPL < $155: Perda = Premium

Put Option (Opção de Venda)

Direito de vender uma ação a um preço fixo (strike) até uma data específica.

Exemplo:
AAPL a $150 → Put $145
Se AAPL < $145: Lucro = ($145 - Preço) - Premium
Se AAPL > $145: Perda = Premium
